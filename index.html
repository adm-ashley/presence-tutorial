What You’re Building

how it fits together
ultrasonic sensor
   │  distance in cm
   ▼
ESP32-C3  ──  Wi-Fi  ──►  Firebase Realtime Database
                           /sensor
                             distance: 42.5
                             near:     true
                             updatedAt: (server time)
                                │
                                ▼  live updates
                          your p5.js page on Firebase Hosting
                          (laptop, phone, projector…)
You’ll need
  • ESP32-C3, 3.3 V HC-SR04 sensor (HC-SR04P), jumper wires
  • Google account for Firebase
  • Node.js for hosting
  • 2.4 GHz Wi-Fi network the board can join (phone hotspot works)
Files you’ll edit
  • presence_sensor/presence_sensor.ino · Wi-Fi, database address, pins
  • docs/config.js · your Firebase project, once
  • docs/sketch.js · the interaction, as much as you like
  • Leave firebase_plumbing.h and docs/lib/ alone: they do the connecting for you

Run the Page

DoOpen the docs folder in your editor and start Live Server.

ExpectThe label in the top right reads live · 120 cm or similar. Walk up to the sensor: the page darkens, a light grows, a line of text fades in.

CheckThe page reacts to your own sensor, not just the mouse.

The status label tells you where the chain breaks
  • live · readings arriving
  • board offline · readings stopped: check the board’s power and Wi-Fi
  • waiting for the board · nothing has ever arrived at /sensor
  • permission denied · the rules from Step 3 aren’t published
  • practice mode · config.js still has the placeholder: the mouse is the sensor (bottom of the page = close)

Whole sketch.js from the kit
docs/sketch.js · paste to start again
/*
  DM3014 · Presence · page sketch
  ------------------------------------------------------------------
  This is the file you edit. When someone walks up to the sensor,
  the page darkens, a light grows, and a line of text appears.
  When they leave, it fades back.

  Everything about Firebase is in lib/sensor.js. From here you only need:

    sensor.distance          latest distance in cm (-1 = nothing in range)
    sensor.near              true while someone is close
    sensor.online            true while the board is sending
    sensor.on("near", fn)    runs once when someone arrives
    sensor.on("far", fn)     runs once when they leave
*/

// ── Settings ─────────────────────────────────────────────────────
const FAR_CM = 200;          // treat anything further than this as "nobody"
const DAY = "#efe9dc";       // background when nobody is near
const NIGHT = "#12151c";     // background when someone is right there
const LAMP = [255, 208, 140];

// One of these appears each time someone arrives.
const LINES = [
  "Oh. You're here.",
  "Stay a little longer.",
  "Closer, and I'll keep talking.",
  "Most people walk straight past.",
];

let smooth = FAR_CM;   // eased distance, so the page moves gently
let shown = 0;         // how visible the text is, 0 to 1
let line = "";


// ── Setup ────────────────────────────────────────────────────────

function setup() {
  createCanvas(windowWidth, windowHeight);
  textAlign(CENTER, CENTER);

  sensor.connect(firebaseConfig, DATA_PATH);

  sensor.on("near", () => {
    line = random(LINES);
  });

  sensor.on("far", () => {
    console.log("they left");
  });
}


// ── Draw ─────────────────────────────────────────────────────────

function draw() {
  // 1. Ease towards the latest reading. Readings arrive twice a
  //    second; easing fills in the gaps.
  const target = sensor.distance > 0 ? min(sensor.distance, FAR_CM) : FAR_CM;
  smooth = lerp(smooth, target, 0.08);

  // 2. Closeness: 0 when far away, 1 when right at the sensor.
  const closeness = constrain(map(smooth, FAR_CM, 10, 0, 1), 0, 1);

  // 3. The room darkens as they come closer.
  background(lerpColor(color(DAY), color(NIGHT), closeness));

  // 4. A light that grows with closeness.
  noStroke();
  for (let i = 6; i > 0; i--) {
    fill(LAMP[0], LAMP[1], LAMP[2], 40 * closeness);
    circle(width / 2, height / 2, i * 90 * closeness);
  }

  // 5. The line fades in while they're near.
  shown = lerp(shown, sensor.near ? 1 : 0, 0.06);
  fill(255, 255 * shown);
  textFont("Karla");
  textSize(min(width, height) * 0.05);
  text(line, width / 2, height / 2 + min(width, height) * 0.28);

  // 6. The raw reading, small, bottom left.
  fill(closeness > 0.5 ? 200 : 60);
  textFont("JetBrains Mono");
  textSize(12);
  textAlign(LEFT, BOTTOM);
  text(sensor.distance < 0 ? "— cm" : nf(sensor.distance, 1, 1) + " cm", 16, height - 16);
  textAlign(CENTER, CENTER);
}

function windowResized() {
  resizeCanvas(windowWidth, windowHeight);
}

Host It on Firebase

DoOpen a terminal in the kit folder: the one with firebase.json in it. Type node -v: it should print v20 or higher. If it’s older, or not found, install the LTS version from nodejs.org first.

DoRun the login command. A browser opens: sign in with the same Google account you used for Firebase.

DoRun the deploy command, with your own project ID in place of dm3014-yourname. It’s the projectId in your config.js.

ExpectDeploy complete! and a Hosting URL ending in .web.app. That’s your page’s public address.

Troubleshooting

Board

  • Blank Serial Monitor → USB CDC On Boot is off. Turn it on, upload again, press reset.
  • Dots that never finish → wrong Wi-Fi name or password, a 5 GHz network, or a network with a login page.
  • Distance always −1 → TRIG and ECHO swapped, or an older 5 V-only HC-SR04 that won’t run on 3V3. Swap it for a 3.3 V one; don’t move VCC to 5V.

Firebase

  • replied 401 → the rules from Step 3 aren’t published.
  • replied 404 → the database URL in the board sketch is wrong.
  • “Hosting site not found” when deploying → tick Hosting on the web app (Step 3), or open Hosting in the console and click Get started.

Page

  • Stuck on practice mode → config.js still has the placeholder.
  • “waiting for the board” → the board and the page point at different projects or paths.
  • “permission denied” → the rules from Step 3 aren’t published.
  • Works on Live Server but not online → save config.js and deploy again from the kit folder.
